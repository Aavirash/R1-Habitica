Habitica for R1

Track habits, dailies, and todos — right on your Rabbit R1.

Install:
  1. Open the Creations card on your R1
  2. Tap Add via QR code
  3. Scan the QR code above
  4. Get your User ID & API Token from habitica.com → Settings → API
  5. Open the creation and paste your credentials
Open source at github.com/Aavirash/R1-Habitica
